## 📌 Project Overview

The **Omni-App Voice Automation & Intent Orchestration Framework** is an AI-powered voice interaction platform designed to recognize natural-language commands, identify user intent, extract product entities, and route search requests to the appropriate application.

The platform provides a unified voice-driven interface for multiple e-commerce and food delivery applications, eliminating the need to manually navigate between individual platforms.

Users can speak or type commands such as:

- "Search for a 12GB RAM mobile phone on Amazon."
- "Find a kurti on Meesho."
- "Search for pizza on Zomato."
- "Find paneer on Swiggy."
- "Search for a mobile phone on Flipkart."

The system identifies the target application and processes the corresponding intent.

## 🎙️ How to Use

1. Open the [Live Application](https://rames-qa.github.io/Amazon-Automation-Testing-Framework/).
2. Enable microphone access when prompted.
3. Click **Start Voice Listener**.
4. Speak a natural-language search command.
5. Allow the system to identify the product and target application.
6. Review the detected intent and execution telemetry.
7. Use the **Okay** trigger or manual capture option to generate screenshot evidence.

You can also use the predefined quick-test commands to evaluate different application routes.
